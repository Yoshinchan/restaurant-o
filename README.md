# EMBER & OAK

A static, responsive restaurant website concept created for the LunarStudio portfolio. All menu content, prices, seating times, hours, and contact details are illustrative. The reservation form is a front-end demonstration and does not create or send a booking.

## Run locally

Open `index.html` in a browser, or serve this folder with any static file server, for example:

```sh
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy

Deploy the repository root as a static site. For GitHub Pages, choose the `main` branch and `/ (root)` in the repository's Pages settings. No build step is required.

The site uses Google Fonts and Unsplash image URLs; those assets require internet access. CSS color fallbacks are provided, and JavaScript substitutes a gradient if an image fails to load.
